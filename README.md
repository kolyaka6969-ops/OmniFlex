# OmniFlex

Остров вверху экрана и микшер громкости для Windows 10/11. Написан на Rust. Включает все функции Volumix 1.6.8,
кроме островка с плеером.

## Остров

Чёрная пилюля посередине вверху экрана, поверх всех окон. Фокус у активного окна не забирает.

- В свёрнутом виде: часы, раскладка клавиатуры, Caps Lock, заряд батареи, таймер. Точки показывают, что программа
  слушает микрофон (оранжевая) или смотрит в камеру (зелёная)
- На миг раскрывается, когда что-то произошло: сменилась громкость, раскладка или Caps Lock, подключили или
  отключили зарядку, программа включила микрофон или камеру, вышло время таймера
- Под курсором раскрывается в панель: часы и дата, громкость с ползунком, кнопка микрофона, таймер на 1–30 минут
  (пауза, +1 минута, стоп)
- Колёсико мыши над островом меняет общую громкость
- Во время игр и в полноэкранных окнах прячется (используется детектор игр из Volumix)
- Правый щелчок открывает меню: микшер, настройки, спрятать остров

## Панель острова и инструменты

- Раскрытый остров: крупные часы, вкладки сегментами «Пульт», «Время», «Лента»; инструменты круглыми кнопками,
  плеер с обложкой-пластинкой, громкость капсулой, микрофон и устройство, лаунчер внизу; блоки в тонкой рамке
- Свёрнутый остров: кнопки «назад», «пуск/пауза», «вперёд», пока в любой программе есть трек (наведение на них
  остров не раскрывает)
- Пилюля во время музыки: обычная, пошире (трек, время, кнопки) или мини-плеер; строка песни в такт музыке
  (в мини-плеере и в своей пилюле), край-эквалайзер: столбики, волна, точки, светящаяся кромка, радуга, зеркало
- Скриншоты области и всего экрана в буфер и в папку, разметка (стрелка, рамка, маркер, текст, размытие),
  ссылка через Imgur или ImgBB со своим ключом
- Текст с экрана (русский и английский распознаватели Windows), QR-код, пипетка с лупой и историей цветов,
  запись экрана в MP4 (H.264) или GIF, вставка без форматирования
- Лаунчер: перетащить ярлык на остров, перетащить ярлык на ярлык — группа, плюс — ссылка или команда
  (`steam://run/…`), свой значок, горячая клавиша для ярлыка
- Напоминания по дням недели и таймер — карточкой со звуком
- Уведомления Windows карточкой (читаются из базы центра уведомлений)
- Голос в текст (распознавание Windows или Whisper), ИИ через любой OpenAI-совместимый API
- Claude Code и Codex: статус на острове, ответ Claude Code на разрешения прямо с острова; подключаются в настройках
- Меню острова (правый щелчок, выбор устройства и плеера) нарисованы в его стиле и теме
- Остров перетаскивается мышью за пустое место (вдоль края, вниз, на другой монитор), Ctrl + колёсико меняет
  размер, в меню — «Вернуть на место и обычный размер»
- Автоскрытие: в покое остров уезжает за верхний край и возвращается, когда к нему подводят курсор
- Тема, размер 80–200 %, прозрачность, монитор и сдвиг, сквозной режим (`OmniFlex.exe --click-through on|off|toggle`),
  скрытие от захвата экрана, свои устройства звука, русский и английский

Проверка отрисовки без экрана: `OmniFlex.exe --render-test <папка> [обложка]` сохраняет кадры острова в PNG.

## Из Volumix

- Громкость и отключение звука для каждого приложения, общая громкость, индикаторы уровня
- Выбор устройства вывода (оно становится устройством по умолчанию в Windows)
- Значок в трее: левый щелчок открывает компактный микшер, правый — меню
- Глобальные горячие клавиши: громче, тише и без звука для активного окна, отдельного приложения или общей
  громкости; открыть микшер; следующее устройство вывода. Новые действия: включить/выключить микрофон, показать или
  спрятать остров
- Всплывающий индикатор громкости внизу экрана
- Песня и текст на рабочем столе вместо обоев: обложка, бегущая строка, прогресс, кнопки управления, синхронный
  текст. Источники песни: Spotify, Яндекс Музыка, YouTube (в том числе в браузере). Тексты ищутся в lrclib, NetEase,
  Kugou, text-lyrics.ru, amalgama-lab, Genius и lyrics.ovh. Обложки — в Deezer, iTunes и Genius, а также кадр
  с YouTube и блок «Музыка» в описании ролика. Опенинги аниме определяются через AnimeThemes. Свои тексты кладутся
  в `%APPDATA%\OmniFlex\lyrics`
- Автозапуск с Windows (сразу в трей), светлая, тёмная или системная тема

## Сборка

Нужны Rust (`winget install Rustlang.Rustup`) и Visual Studio Build Tools с компонентом C++.

```powershell
cargo build --release
```

Результат: `target\release\OmniFlex.exe`, один файл без зависимостей.

Значок `res/app.ico` генерирует скрипт `python tools/make_icon.py`.

Настройки хранятся в `%APPDATA%\OmniFlex\settings.json`, ошибки пишутся в `error.log` в той же папке.

## Устройство

| Поток | Что делает |
|---|---|
| главный | окно настроек (egui): микшер, горячие клавиши, настройки |
| `shell.rs` | трей, горячие клавиши, Core Audio (`audio.rs`), остров (`pill.rs`), индикатор громкости (`osd.rs`), микшер у трея (`flyout.rs`) |
| `core.rs` | медиа-сеансы Windows (`media/session.rs`), логика обоев (`desktop/controller.rs`) |
| `desktop/` | окна в слое обоев под значками, отрисовка (`view.rs`), хук мыши для кнопок (`pointer.rs`) |

Свои окна рисуются через tiny-skia (`gfx/`) и выводятся как слоистые окна WinAPI. Сетевые запросы выполняются
в tokio, ответы возвращаются в поток ядра.
